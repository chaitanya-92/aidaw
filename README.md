# AI DAW

An AI-native browser music studio focused on preserving real vocal performances while generating and arranging instrumental accompaniment.

## Product direction

- Browser-first, multitrack DAW workflow
- Vocal import and non-destructive playback
- AI-assisted accompaniment generation
- Editable arrangement and mixing controls
- Suno Studio-inspired workflow patterns, with original branding and UI implementation

## Status

Project initialized. The first milestone is a working studio-shell prototype with local vocal import, playback, an editable arrangement scaffold, basic mix controls, and a procedural beat preview. This is not yet a production-quality DAW or an AI music-generation model.
